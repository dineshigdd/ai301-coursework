I fixed a persistent table alignment bug in Kaoto's open-source visual integration builder so path and query parameter columns line up vertically in the component properties modal. 

As a student at CodePath, I tackled a front-end issue where parameter tables in the Endpoint Options tab misaligned due to independent width calculations. Instead of applying a temporary style patch, I restructured the component's layout code to render parameter groups as shared row groups within a single table, backed by comprehensive unit tests. 

My pull request was officially reviewed, approved, and merged into the official Kaoto repository!

You can check out my merged pull request and code changes [here](https://github.com/KaotoIO/kaoto/pull/4412#issue-6322633045).
